# Publication boundaries

Never commit or upload student photos to GitHub or include them in any release.
Keep Photos, Spreadsheet, Output, config.json, and service-account credentials local.
Do not add private workspace folders to PyInstaller data or other application resources.
Run scripts/audit_private_data.py on tracked source and on every release archive before publication.
Source and release archives may include only application code, dependencies, house backgrounds,
fonts, logos, banner artwork, and the application icon.
